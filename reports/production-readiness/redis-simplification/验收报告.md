# Redis 支持范围精简

## 目标与边界

脚手架面向中小型项目：Redis 默认单机，最多支持哨兵；不预置分片集群和为其服务的额外抽象。保留上轮与拓扑无关的缺陷修复，不升级依赖、不改变真实运行配置。用户后续已确认按主题整理本地提交，不推送远端。

## 覆盖计划

- 配置：四个 Redis 使用方默认单机、可配置哨兵、独立 DB 保持；不支持的旧模式明确拒绝；内存限流不要求 Redis。
- 工厂：保留单机/哨兵选项映射、错误日志和连接关闭测试。
- 缓存：保留批量顺序、序列化错误、TTL、空批次、写入前校验、计数及脚本行为，用单 Redis 验证。
- 锁：去掉分片限制，保留多资源、重试、租约、错误传播和资源校验。
- 队列：由 BullMQ 管连接，保留并发配置修复；单 Redis 验证重新启动后的限制设置/保留/清除，以及执行中任务正常停机。
- 回归：类型、lint、构建、全部测试和既有单元覆盖率门槛；文档、示例、技能规范同步。
